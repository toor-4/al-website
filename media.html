Field Guide

The verbs, the codes, the anatomy.

Everything on the live demo and in the waiter analogy, laid out as a quick reference — the four verbs you'll actually use, the status codes worth memorizing, and what a request looks like under the hood.

Four verbs, one conversation

Every request tells the API what kind of favor you're asking for.

GET

Asking what's on the menu — read-only, nothing changes.

GET /menu/steak
POST

Placing a brand new order — creates something that didn't exist.

POST /orders
PUT / PATCH

Sending the order back to fix it — updates what's already there.

PATCH /orders/42
DELETE

Canceling the order entirely — removes it for good.

DELETE /orders/42

Status codes worth memorizing

The waiter always comes back with a number. Here's what the common ones actually mean.

2xx — Success

200

OKHere's what you asked for.

201

CreatedMade the thing. Here it is.

204

No ContentDone. Nothing to send back.

3xx — Redirection

301

Moved PermanentlyIt lives somewhere else now.

304

Not ModifiedSame as what you already have.

4xx — Client Error

400

Bad RequestThat request didn't make sense.

401

UnauthorizedWho are you, exactly?

404

Not FoundNothing lives at that address.

5xx — Server Error

500

Internal Server ErrorSomething broke back here.

503

Service UnavailableDown for a moment. Try again.
